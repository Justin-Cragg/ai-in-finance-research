## Executive summary
- Prophix is positioned as **"AI-powered finance for mid-market complexity"**: one platform for budgeting, reporting and consolidation, priced below the enterprise suites.
- **Sept 2025: launched what it calls "the first suite of autonomous agents" for finance.** The **Budgeting Agent** sets up budgets and validates submissions and approvals; the **Reporting Agent** detects variances and generates reports; the **Modeling Agent** builds and maintains models. Budgeting and Reporting went live for **all customers** on 27 Sept 2025. [2]
- **Sept 2026 (Fall release):** **Autonomous Planning Agent** (runs recurring FP&A processes with governed workflows and human oversight) and the **Prophix One MCP Server**, which connects Prophix data to the client's enterprise AI tools. [1]

## How the AI works — plain English

### Prophix One Agents [1][2][4]
| Agent | What it does | Status |
|---|---|---|
| **Reporting Agent** | Ask "What are operational costs for 2025?" and get tables, charts and breakdowns; detects variances | Available |
| **Budgeting Agent** | Sets up the budget cycle; checks submissions and approvals to cut rework | Launched Sept 2025 [2] |
| **Modeling / Architect Agent** | Turns a customer's data and reports into a validated Prophix model "in hours rather than weeks" | Rolling out [4] |
| **Consolidation Agent** | Natural-language questions over the consolidation audit trail: group totals, top contributors, unusual or negative balances | Announced for spring 2026 [4] |
| **Autonomous Planning Agent** | Automates recurring FP&A processes inside governed workflows | Fall 2026 release [1] |

### Prophix One MCP Server [1]
- Exposes Prophix data and "intelligence" to the organisation's broader AI ecosystem through the open MCP standard, keeping Prophix as the governed source. Prophix hasn't named specific assistants; any MCP-capable assistant should be able to connect, but verify.

### Design principles [1][2]
- "One governed system that is **deterministic, explainable and audit-ready**." Policy-first guardrails, full audit trails, and **customer data not used to train external models** (TrustArc certified). A CFO customer quote stresses being able to *trace exactly where results came from*.

## Where it lands in the finance process
| Process | AI help | Human still owns |
|---|---|---|
| Budget cycle | Budgeting Agent sets up and checks submissions | Targets, approvals |
| Monthly reporting | Reporting Agent: variance detection and Q&A | Commentary to board |
| Consolidation | Consolidation Agent queries over audit trail | Eliminations, sign-off |
| Implementation / change | Architect Agent builds models from existing reports | Design decisions |

## Governance & control considerations
- Agent rollout has been **staggered**. As at Sept 2026 third-party sources report only the Reporting Agent as broadly available, so **check per-agent GA** before positioning. [4]
- Prophix's own CFO reported a **50% cut in monthly close time** in early internal testing. That's a vendor's own team, so treat it as indicative only. [2]
- Models used are not disclosed. Ask for the subprocessor list and hosting region for NZ clients.

## Presentation talking points
- Shows **agentic FP&A reaching the mid-market**, not just Anaplan/Oracle-scale clients.
- Architect Agent addresses a real NZ constraint: **implementation capacity**. If AI builds the first model from existing Excel reports, time-to-value shrinks.
