## Executive summary
- **Xero is the centre of gravity for the vCFO deck.** Its AI is moving from "help me code a transaction" to agents that do the bookkeeping, chase documents and prepare month-end — with the accountant approving.
- **Live today:** Smart Document Capture (reads invoices/receipts straight into Xero) and **Auto Bank Reconciliation** (100m+ transactions auto-reconciled; explains each match). [1]
- **Open by design:** Claude powers JAX, and Xero data is accessible *from* Claude.ai, ChatGPT and Microsoft 365 Copilot — so an advisor can model scenarios on live client data in the AI tool they already use. [1][3]

## How the AI works — plain English

### 1. Bookkeeping automation (live) [1][2]
| Capability | How it works |
|---|---|
| **Smart Document Capture** | JAX reads source documents (invoices, receipts) and extracts the data directly into Xero — no separate capture app |
| **Auto Bank Reconciliation** | Matches high-confidence bank lines to transactions in real time and shows *why* it matched; split payments (sale vs fees) coming |
| **Bill Protection** | Flags unusual amounts, changed bank details or unfamiliar suppliers before payment — a fraud control |
| **Payment Follow-Ups** | Analyses customer payment history and runs tailored collection strategies |

### 2. Agents for the practice / month-end (early access → GA later 2026) [1]
- **XeroForce** — build custom agents in natural language on Xero OS. Pre-built **month-end agent** reviews document reconciliation and posts prepayment/amortisation journals, then gives the user a full action summary to accept.
- **Document Requests** — JAX requests missing documents from clients, sends reminders, answers clarifications, matches docs to transactions (client approves each step).
- **Xero Partner Hub** — live "book health" and month-end readiness across all practice clients: unreconciled items, duplicates, missing documents, anomalies.

### 3. Advisory / vCFO features (coming soon) [1]
- **Cash Flow Actions** — predicts cash gaps before they happen and suggests actions (e.g. delay non-critical bills).
- **Scenario Planning** — model price rises, cost increases, hiring on live Xero data; paired with **Industry Benchmarks**.

### 4. Xero in other AI tools [1][3]
- **Claude** (Anthropic partnership, Mar 2026): Claude powers JAX; Xero data available inside Claude.ai for analysis and planning; data used only for the user's session, not for training.
- **ChatGPT** connector and **Microsoft 365 Copilot** (Excel, Word, PowerPoint, Copilot Cowork) — live Xero data into charts, tables and documents; multi-client switching for advisors.

## Where it lands for a vCFO practice
| Work | AI help | Advisor still owns |
|---|---|---|
| Bookkeeping & coding | Doc capture, auto bank rec | Exceptions |
| Month-end | XeroForce month-end agent, Partner Hub readiness | Review and sign-off |
| Client chasing | Document Requests | Relationship |
| Cash & advisory | Cash Flow Actions, scenarios, benchmarks, Claude/ChatGPT/Copilot analysis | Advice, judgement |

## Governance & control considerations
- "Accountable Intelligence": agents produce action summaries for human acceptance. [1]
- Regional availability is often US/UK-first — **check NZ availability feature by feature**. [1]
- Practices need a policy on which external AI tools may connect to client ledgers.

## Presentation talking points
- The vCFO model shifts from *doing the books* to *supervising agents across a client portfolio* (Partner Hub + XeroForce).
- Strong NZ story: NZ-founded platform partnering with a frontier AI lab.
